# AI 코딩 도구 커스터마이징 — 일반 테크용 LinkedIn 게시물

AI 코딩 도구, "설치만 하면 끝"이 아닙니다.

요즘 개발자들 사이에서 AI 코딩 도구(Claude Code, Cursor, Copilot 등)가 빠르게 퍼지고 있습니다. 하지만 대부분 기본 설정 그대로 사용합니다. 스마트폰을 사서 기본 앱만 쓰는 것과 비슷합니다.

반년간 7개 프로젝트를 혼자 관리하면서 발견한 3단계 커스터마이징을 공유합니다.

---

## 1단계: AI에게 "우리 팀 문화"를 가르치기

AI에게 코드를 시키면 매번 "이 프로젝트에서는 이렇게 해주세요"라고 반복 설명해야 합니다. 신입사원에게 매일 같은 말을 하는 것과 같습니다.

**해결책**: 프로젝트마다 "AI용 매뉴얼"을 만듭니다.

이 매뉴얼에는 프로젝트의 기술 구조, 코딩 규칙, 자주 쓰는 명령어가 담겨 있습니다. AI는 매 대화 시작 시 이 매뉴얼을 자동으로 읽고, 프로젝트 맥락을 이해한 상태에서 작업합니다.

**결과**: "한국어로 답변해주세요", "TypeScript 쓰지 마세요" 같은 반복 지시가 완전히 사라졌습니다. 현재 7개 프로젝트(웹서버, 모바일앱, AI 분석 등)에 각각 다른 매뉴얼을 두고 있으며, 프로젝트를 전환해도 AI가 즉시 맥락을 파악합니다.

추가로 **전문 도구 확장**(플러그인)을 설치하면 보안 취약점 탐지, 자동 코드 리뷰 등이 기본으로 동작합니다. 현재 13개 전문 플러그인을 사용 중입니다.

---

## 2단계: AI의 실수를 자동으로 잡는 안전장치

AI가 작성한 코드를 사람이 매번 검토하는 것은 비효율적입니다. 자동차에 차선 이탈 경고가 있듯이, AI에게도 안전장치를 달 수 있습니다.

**자동 교차 검증**: AI(Claude)가 코드를 수정할 때마다, 다른 AI(OpenAI Codex)가 자동으로 보안 취약점, 버그, 성능 문제를 검토합니다. 사람이 개입하지 않아도 두 AI가 서로 교차 검증하는 구조입니다.

**맞춤 도구 22개**: 반복 작업을 자동화하는 도구를 직접 만들 수 있습니다.
- 코드 변경사항을 분석해서 커밋 메시지를 자동 생성하는 도구
- 프로젝트별 작업 보드를 AI가 직접 관리하는 도구
- 코드 변경 시 관련 파일 간 일관성을 자동 검증하는 도구

**실시간 대시보드**: AI가 현재 얼마나 "기억력"을 사용하고 있는지, 남은 용량은 얼마인지, 이번 주 사용량은 어느 정도인지 한눈에 볼 수 있습니다. 마치 자동차 계기판처럼, AI의 상태를 실시간으로 모니터링합니다.

---

## 3단계: AI 팀을 만들어 일하기

가장 큰 변화는 "하나의 AI"가 아니라 **"역할이 분담된 AI 팀"**을 구성한 것입니다.

**30명의 AI 전문가 팀**: 설계자, 개발자, 테스터, 보안 전문가, 코드 리뷰어 등 30개 이상의 전문 역할을 정의해뒀습니다. 작업이 들어오면 적절한 전문가가 자동으로 배치됩니다.

**자동 난이도 분배**: 간단한 작업(파일 검색, 빠른 조회)은 가볍고 빠른 AI 모델이, 복잡한 작업(시스템 설계, 대규모 리팩토링)은 정밀한 AI 모델이 맡습니다. 사람이 일일이 지정하지 않아도 자동으로 라우팅됩니다.

**자동 파이프라인**: 계획 수립 → 요구사항 정리 → 구현 → 검증 → 수정의 과정이 자동으로 순환합니다. 검증에서 문제가 발견되면 자동으로 수정 단계로 돌아갑니다.

**병렬 처리**: 최대 5개의 AI 에이전트가 동시에 독립적인 작업을 수행합니다. 순차적으로 하나씩 하는 것이 아니라, 할 수 있는 일을 동시에 진행합니다.

**멀티 AI 협업**: Claude(Anthropic)가 코드를 작성하면, Codex(OpenAI)가 검증하고, Gemini(Google)가 문서를 작성합니다. 서로 다른 AI의 강점을 조합한 파이프라인입니다.
